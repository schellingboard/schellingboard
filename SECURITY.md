# Security policy

## Reporting a vulnerability

Please do not open a public issue. Report it privately through
[GitHub private vulnerability reporting](https://github.com/schellingboard/schellingboard/security/advisories/new).
You get an acknowledgement within 7 days.

## Supported versions

Only the latest release receives security fixes.

## What is not a vulnerability

In an Open event, visitors can pick a name without verifying it. That is a deliberate choice of the
organizer, see
[How it works](https://github.com/schellingboard/schellingboard/blob/main/docs/public/organizers/how-it-works.md).
