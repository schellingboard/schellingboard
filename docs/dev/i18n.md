# Internationalisation

The web app uses [Lingui](https://lingui.dev) (ICU messages, source strings as keys). Catalogs are
plain `.po` files in `apps/web/locales/<locale>/messages.po`, committed. `en` is the source; other
locales load on demand. The plan and open steps are in issue #1328.

## Adding a string

1. Write the text with a macro: `` t`Save` `` (from `@lingui/core/macro`) or `<Trans>Save</Trans>`
   (from `@lingui/react/macro`). Plurals use ICU (`plural(...)`).
2. Run `make i18n-extract`. It updates every catalog; commit the result.
3. Translations go into the other locales' `.po` files (none yet besides `en`).

User-written content (titles, bios) is never translated.

## Formatting

Dates, times and relative times follow `useFormatLocale()`: the app's language, with the region the
browser asks for when it is the same language. The event's time zone stays separate. See
`apps/web/src/i18n/format.ts`.

## Guardrails

- **Lint:** `lingui/no-unlocalized-strings` flags literal text in JSX. It only runs on the files
  listed in `eslint.config.mjs`: today the ones that simply have no literal strings (none uses a
  macro yet). Step 5 of #1328 adds an area at a time; add a file when its strings are in the
  catalog. When the list becomes `apps/web/src/**`, also set `ignoreFunctions` (`Error`,
  `console.*`) and exclude `**/*.test.tsx`. The rule does not flag `title=` attributes: check those
  by hand.
- **Catalogs:** `make i18n-check` (part of `make precommit`) runs `lingui extract --clean` and fails
  when that changed a catalog, and when a translated locale has a missing or empty message. Run
  `make i18n-extract` and commit.
- **Pseudo-locale:** `pseudo-LOCALE` accents every message so hard-coded strings stand out (they
  stay plain), and pads each by about 30% with `~` so overflowing layouts show. It is generated from
  `en`, development only, and not in the settings switcher. Turn it on with
  `localStorage.setItem("sb-pseudo", "1")` and reload; the server's stored language does not
  override it. Production builds ignore it.
