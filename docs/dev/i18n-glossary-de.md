# German glossary

Terms of the German catalog (`apps/web/locales/de/messages.po`), chosen by the implementing agent
for the owner to review. Changing a term means editing every message that uses it; search the
catalog for the old word.

**Address:** informal _du_ throughout (imperatives such as "Wähle", possessives such as "dein"), the
tone of a community event tool. Genders are avoided with neutral wording, no stars or colons:
_Teilnehmende_, _Organisierende_, _eine teilnehmende Person_, _Abstimmende_.

| -------------- | ------------------- | ------------------------------------------------------------------- |
| session        | Session             | Loan word, as at German tech events                                 |

| attendee       | Teilnehmende(r)     | Plural _Teilnehmende_, singular _teilnehmende Person_               |
| organizer      | Organisierende      | "eine organisierende Person" for one                                |

Kept in English: SchellingBoard, CSV, Markdown, Discord, WhatsApp, Telegram, Signal, pronoun
examples (they/them), and the Lingui and HTML syntax inside messages. Statistics wording follows the
English closely; terms such as "Trichter" (funnel) and "Auslastung" (utilization) are the plain
German ones.
